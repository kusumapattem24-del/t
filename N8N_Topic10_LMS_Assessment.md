# Topic 10 LMS Assessment Document

**Agent Orchestration, Alerting, and Human-in-the-Loop – Implement a Live Human Approval Workflow**

## 1. Assessment Overview

This assessment evaluates your ability to design, build, test, validate, and document a Human-in-the-Loop (HITL) approval workflow in n8n with AI safety controls, approval routing, workflow pausing, resume links, and centralized error handling.

## 2. Assessment Objective

Demonstrate the ability to implement a complete HITL workflow using AI Agents, Wait nodes, approval forms, Slack/Email notifications, Error Trigger workflows, and governance controls.

## 3. Prerequisites

- Review the Requirement Document.
- Review the Implementation Guide.
- Complete Topics 1–9.
- Active n8n instance with LLM and notification credentials.
- GitHub account for submissions.

## 4. Assessment Tasks

- Exercise 1 – AI Agent Safety Configuration
- Exercise 2 – Review Notification
- Exercise 3 – Human-in-the-Loop Wait Node
- Exercise 4 – Approval Routing
- Exercise 5 – Human Approval Validation
- Exercise 6 – Error Alert Workflow
- Exercise 7 – Safety Limit Validation
- Exercise 8 – Mini Project: Build a Human-in-the-Loop Approval Workflow

## 5. Practical Assessment Checklist

- [ ] AI Agent Added and Configured

## 6. Assessment Success Criteria

- Configure AI Agent timeout and token limits.
- Generate AI content for human review.
- Send approval requests using secure resume URLs.
- Pause and resume workflows with Wait nodes.
- Route approval and rejection paths correctly.
- Implement centralized Error Trigger notifications.
- Complete an end-to-end HITL workflow.
